Radio Command Center
====================

Installation
------------
1. Drag “Radio Command Center” into the Applications folder.
2. Open it from Applications.
3. Sign in as the administrator and choose the mounted recording folder.

The application includes its transcription engine and model. No separate Python
installation is required. Application data, logs, and the transcript database
are stored in:

~/Library/Application Support/Radio Command Center

This build is for Apple silicon Macs running macOS 13 or newer.
